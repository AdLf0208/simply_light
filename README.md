# Simply Light

A Horizon port of [Simply Light 1.5.3+1.21.1-b4](https://github.com/Flanks255/simplylight)
(MIT, by Flanks255) for Minecraft Java 26.3: **one hundred and sixty light-emitting
decorative blocks** in ten families × sixteen dye colours — off and on lamps,
slabs, panels, wall lamps, bulbs, rod lamps, three-block lamp posts, and edge
lights (bottom and top).

This is a **content mod** (mod API `0.2`, registry kind `mod`): one flat `.hmod`
holding the block declarations, states, models, textures, loot tables and 234
recipes in `data/` and `assets/`. It carries **no code** — no crate, no hooks, no
native half — so it loads on any Horizon at the mod API it names.

## Install

Put `simplylight.hmod` in the game folder's `horizon-mods/` and turn it on in
Options > Mods. The game reads content once at start, so restart after adding it.
Servers and LAN guests need the same file.

## Build and check

```bash
cargo horizon-mod build          # -> target/horizon-mod/simplylight.hmod
cargo horizon-mod check simplylight.hmod
```

`check` validates the manifest, the package layout and the content root. There
are two in-game legs, both launching a game at the mod API pin with
`--dev-mod simplylight.hmod` (see each script's header for the exact command):
`tools/e2e.sh` (ids, 2048 states, light, drops, items, placement) and
`tools/data_parity.sh` (every carried recipe, every loot table, and water flowing
into the waterlogged families).

| `data/simplylight/recipe/` | 234 | block, bulb, edge, slab, panel, rod, wall lamp, post, dye and toggle |

The `assets/` and `data/` trees are generated by
[`tools/gen_content.py`](tools/gen_content.py) from the upstream jar: its
`assets/` and `data/` are copied (and upgraded to the 26.3 formats), and the 160
block declarations plus the 83 recipes the carry tool could not place are written
from the behaviour read in upstream's Java source. The jar itself is the evidence
in `ports/_shared/carry-work/simplylight/`.

## Scope and gaps

Measured in game on this package (2026-11-21, Horizon `0a875da`): all 160 ids
register, **2048/2048 states bind**, the light levels are upstream's (15 for
panel/slab/wall/rod/post/on lamp, 14 for bulb and edge lights, 0 for the off
lamp), all **234 recipes** craft their declared result with the ingredients
consumed, all **160 loot tables** give exactly their own block, the tags resolve,
the items place, the tab lists 160, and the eight waterlogged families take
water at placement.

Not ported (recorded in `notes.md`): the redstone toggle of the lamps, the
lamp-post column's per-position light and place/break cascade, the edge-light
editor screen, tooltips, the lamp-post item's attack damage, and the `Equipable`
head slot. Three template-derived deviations are measured, not assumed — see
`notes.md` §"Behaviour carried, and measured deviations".
